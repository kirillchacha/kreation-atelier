# Kreation-Atelier - Creative Communication Studio Website

A fully responsive website for Kreation-Atelier, a creative communication studio ("kreativkommunikation") based in Oberuzwil, Switzerland, featuring extensive photo galleries, a family training program page, and multilingual support.

## 🔗 Live Demo

[https://kirillchacha.github.io/kreation-atelier/](https://kirillchacha.github.io/kreation-atelier/)

## ✨ Features

- **Hero section** - introduction to the studio's creative communication philosophy
- **About section** - team profile featuring Eleonora and inspirational quotes from M. Rumi, M. Gandhi, and V. Satir
- **Extensive photo galleries** - Atelier (20 images), Dietelsberg (51+ images), Mosaikprojekte / mosaic projects (36 images), and Mosaikkugeln / mosaic spheres (4 images)
- **Gordon-Familientraining page** - dedicated page for the family training program
- **Contact section** - address, phone, email, and WhatsApp integration
- **Language toggle** - German and English support
- **Custom 404 page** - branded error page
- **WebP image optimization** - fast-loading, optimized imagery
- **Fully responsive design** - optimized layout for desktop, tablet, and mobile

## 🛠️ Tech Stack

- **HTML5** - semantic markup for structure and SEO
- **CSS** - custom styling for layout, typography, and responsiveness
- **JavaScript** - interactivity and dynamic UI behavior
- **JSON** - structured data for gallery content
- **Custom fonts & icons** - for a polished, on-brand visual style
